# Web研究記事の構成

## 記事の運用ルール

日付付き記事の追加単位、過去記事の保持・訂正メモ、記事間の参照、日付順・テーマ別の一覧を扱う場合は、[research-report-website](../../research-report-website/SKILL.md) を読む。これらの運用ルールは同スキルを正本とし、ここでは表示上の指針を扱う。

## 教科書のように読める表示

- 白または淡い背景、濃い本文、控えめなリンク色、見出しと罫線を基本とする。ヒーロー画像、装飾カード、グラデーション、意味のないアニメーションを追加しない。
- 本文の幅と行間を読みやすくし、見出し階層・図表番号・節へのリンクを整える。余白を大きくしすぎて比較対象が離れないようにする。
- 冒頭の概要、主要な結果表と図、重要な限界は初期表示で読めるようにする。全条件の補助表・完全なコード・長いログは折りたたみに置ける。
- 横長の表はまず列を整理する。必要なら表の領域だけを横スクロール可能にし、ページ全体をはみ出させない。重要な列は省略しない。
- コードは等幅で、表記法を揃える。左右比較が狭い画面で読めない場合は縦に並べる。色だけで方式を区別しない。
- 静的な研究記事の本文・表・リンクは、可能ならJavaScriptなしでも読めるようにする。インタラクティブな図を採用しても、主要な結論と値を静的に残す。

## 根拠への導線

本文の数値と図表を同じ集計元から生成する。読者が閲覧できるデータ・コード・一次資料へのリンクを付け、ホスト上だけにあるパスをWeb閲覧者向けのリンクにしない。個人情報や認証情報を資料へ含めない。

図を共有・印刷する用途ではSVG/PDFなどの単独ファイルも提供する。成果物の形式に応じて印刷表示を確認する。印刷時に主要結果が切れたり、折りたたみの扱いで必要な情報が消えたりしないようにする。

## 変更後の確認

記事一覧から新記事へ、記事から一覧へ戻れることを確認する。変更範囲に応じて、見出し・表・図・資料リンク、狭い画面と通常画面、印刷表示を確認する。既存記事や図の機能を壊していないかを見る。

利用できる公開・プレビュー環境の手順に従う。Sitesを使う作業なら、利用可能なSitesスキルの現行手順を読む。このスキルに特定サイトのID、認証情報、古い公開コマンドを固定しない。
